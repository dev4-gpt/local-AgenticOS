# Veloce Edition Experience

Read `../../VELOCE-EDITION-EXPERIENCE-BLUEPRINT.md` before implementation.

## Workflow

1. Select one of the six Veloce operating chapters.
2. Write one tension, one outcome, one proof artifact, and one next action.
3. Choose the lightest visual form: DOM first, SVG second, procedural Three.js third, video/frame sequence last.
4. Keep interaction state available outside canvas and preserve reduced-motion behavior.
5. Validate desktop, mobile, keyboard focus, and public/private boundaries.

## Guardrails

- Never copy a reference site's assets, copy, source code, or distinctive layout.
- Never put private routes, local files, credentials, provider controls, or raw vault content in public artifacts.
- Never make motion the only way to understand or operate the interface.
