# Veloce commercial model

Veloce sells one governed workspace with scope-based implementation and
optional managed services. The public model is not a set of product editions.

## Base platform

- `$2,500` one-time setup.
- `$1,250/month` platform subscription.
- Isolated tenant runtime, tenant memory, workflows, approvals, audit,
  monitoring, standard support, and up to five named seats.

The base fee does not include provider usage. Capabilities are visible in the
portal, but provider execution, media generation, external delivery, and other
consequential actions remain manifest-, budget-, health-, and approval-gated.

## Scope-based additions

The onboarding scope assessment flags additional work when a request includes
more than five seats, multiple brands, more than three workflows, more than two
integrations, media generation, external publishing/outreach/paid actions,
knowledge migration, priority support, or Veloce-led execution.

The recommendation produces a quote range. An operator approves the commercial
scope and quote before payment and manifest approval. Add-ons include growth,
creative production, integrations, advanced automation, knowledge migration,
additional capacity, external delivery, and managed operations.

## Provider billing

BYOK means the client owns the credential and pays the provider directly.
Veloce-managed means the client purchases a separate prepaid wallet, Veloce
uses a Veloce-owned provider account, and the tenant ledger records estimates,
reservations, settlement, refunds, and provider ownership. Wallet funding never
activates a provider.

## Control-plane sequence

1. Client submits scope and operating requirements.
2. The deterministic recommender records a non-binding recommendation.
3. An operator approves or edits the quote.
4. Approved scope is compiled into the tenant manifest.
5. Payment is created for the approved platform and quote line items.
6. Provider credentials and managed wallets remain separate activation gates.
7. Provisioning and smoke evidence must pass before tenant activation.
