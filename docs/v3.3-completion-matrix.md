## Release decision

Current decision: **controlled beta / test-mode only**.

V3.3 may advance to production only when the full plan’s mandatory acceptance
gates are checked and a current named Cloud Run revision proves the behavior.
Until then:

- Real cards must not be entered against Stripe Test keys.
- Stripe Test payments validate the ledger but do not create provider balances.
- OpenRouter managed execution remains disabled.
- BYOK/provider activation remains provider- and manifest-gated.
- No Supabase or provider secret may appear in evidence.

## Required evidence bundle

1. Git branch and containment report.
2. Source commit and tested image digest.
3. Cloud Run revision and non-secret configuration summary.
4. Migration names/results, not credentials.
5. Static, typecheck, build, and test reports.
6. Stripe Test case IDs and ledger state summaries.
7. Provisioning, isolation, deletion, rollback, and offboarding results.
8. Provider adapter status and pricing-snapshot IDs.
9. Quota, alert, retry, and refund results.
10. Owner approvals for any live-mode or managed-provider gate.
