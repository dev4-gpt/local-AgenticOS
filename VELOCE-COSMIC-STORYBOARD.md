# Veloce AgenticOS Cosmic Storyboard

## Reference Findings

The authorized public reference walkthrough was used to study pacing, not to
copy assets, words, markup, or page composition. The transferable pattern is:

1. One immersive world introduces a subject.
2. A precise product proof artifact grounds that world.
3. Dense detail follows only after the visitor understands the outcome.
4. A visual reset makes the next chapter feel deliberate.

Veloce translates this pattern into operational chapters, not commerce
categories. Its photography, procedural overlays, interface artifacts, and
copy are original.

## Six-Scene Narrative

| Lens | Cosmic state | Operational proof | Visual motion |
|---|---|---|---|
| Signal | Big-bang ignition | Incoming brief and decision signals | Distant dots converge into a first lattice. |
| Memory | Constellation archive | Private vault and grounded brief | Connections settle into linked source clusters. |
| Workflows | Ringed orbital system | Strategy-to-build handoff | Signals travel between named orbital lanes. |
| Human approval | Planetary eclipse | Owner, purpose, decision, audit record | Work pauses at a bright, visible gate. |
| Measured delivery | Observatory orbit | Delivery, cost, and outcome health | Rings stabilize while progress signals resolve. |
| Engage | Return to ignition | A focused 90-day discovery engagement | The system opens into a clear next action. |

## Asset Policy

- Shipped art: optimized original JPEGs in `public-site/src/assets`.
- Local masters: ignored PNGs only, never required for the public build.
- Operational proof: Veloce-owned UI components, sample data, and procedural
  Three.js nodes, rings, and links.
- No reference screenshots, source files, logos, text, or layout extraction.

## What The OS Can Produce

Flow Lab can turn an approved visual reference into an original scene brief,
motion cadence, asset list, and implementation prompts. Web Studio can turn
that brief into a conversion-focused page. Image generation supplies original
photography when a client has not supplied licensed brand imagery. Every final
external deliverable remains human reviewed.
